# Nyxxyr Project Showcase

An editorial project showcase built with Next.js 16, React 19, Tailwind CSS 4, and TypeScript. The front end uses a restrained broadsheet direction: ink-and-paper tokens, asymmetric story composition, press-style project artifacts, and long-form feature routes.

## Routes

- `/` — front-page project showcase
- `/work/[slug]` — statically generated project features
- `/design-system` — live internal design reference (`noindex`)

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Run lint and the production build:

```bash
npm run lint
npm run build
```

If Turbopack cannot spawn its CSS worker in a restricted environment, use the supported Webpack build path:

```bash
next build --webpack
```
